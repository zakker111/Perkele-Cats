# 17 — Accessibility

## Required baseline

- readable text size;
- strong contrast;
- subtitles/text for all spoken dialogue;
- TTS can be disabled;
- reduced motion option;
- reduced beer-distortion option;
- important feedback does not rely on color alone;
- keyboard fallback where feasible for key UI actions;
- clear focus state for menus.

## Psychedelic mode

The full beer effect is optional presentation intensity. Reduced mode should keep the mechanical state but lower motion, distortion, flashes, and screen warping.

## Puzzle accessibility

Puzzles should not depend on rapid timing, tiny hitboxes, or color-only distinctions.

## Health/hazard feedback

Use text/icons/sound in combination when possible. A player should understand that they were damaged without needing to notice one brief animation.
