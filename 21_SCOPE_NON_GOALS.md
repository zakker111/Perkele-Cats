# 21 — Scope and Non-Goals

## Explicitly in scope

- browser game;
- 2.5D tile-based scenes;
- point-and-click interaction;
- inventory;
- pipe/beer equipment;
- six-shot pipe;
- beer surreal state;
- food healing;
- safe puzzles;
- NPCs;
- hammer danger events;
- Perkele cats;
- rare Seppo food rescue;
- dialogue/TTS adapter;
- save/load;
- GitHub Pages deployment.

## Not required for the first release

- multiplayer;
- online accounts;
- procedural open world;
- complex enemy AI;
- realistic weapon simulation;
- crafting trees;
- skill trees;
- hunger/thirst simulation;
- full physics destruction;
- real-time competitive combat;
- mobile-first touch-only redesign;
- mandatory cloud backend;
- professional full voice-acting production.

## Scope rule

A proposed feature must improve the core comedy-adventure loop and fit the small-scene architecture. Otherwise defer it.
